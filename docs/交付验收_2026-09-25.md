# ValuationAgent 交付修复与验收

日期：2026-09-25。适用版本：0.5.0 交付修复工作树；金融小组模型 `1.3.0-finance-team-20260925`，参考模型 `0.3.0-reference`，研究提示版本 `research-2026-09-25.12`。

## 结论与适用范围

本轮目标是把原验收发现的工程阻断修复到可运行、可展示、可追溯和可离线复算。使用现有 Conda `economic_agent`，没有创建或下载新隔离环境，没有修改 Tushare 模块，没有清理用户已有研究、提交代码或发布到外部服务。

这不是“任意公司、任意文件都能自动给出正确估值”的认证。真实 LLM 端到端验收使用明确的合成财务与同业数据；真实比亚迪数据只验证了官方公告检索、年报下载、文本读取和来源保留，没有把合成结果当成比亚迪估值。金融小组金标准对账、行业参数数据授权和现场网络控制仍需正式确认。

## 已完成的修复

| 范围 | 修复及边界 |
| --- | --- |
| 引文准确性 | 不再以“引文中存在数字”视为充分证据；检查科目行、年度列、同一行多年度、主体、单位、合并/母公司口径与披露时点。年份列不可靠、单位缺失等进入警告，不能批量确认。增加千元/百万元等单位，比较百分比列不会挤占金额列。 |
| 同业数据 | 非 Tushare 路径接通可比公司候选与组装，按公司代码隔离冲突；倍数必须绑定对应公司行、匹配定价日并明确 FY 口径。业务可比性及分母对应年度仍需人工复核，不能把 TTM/预测值混入 FY。 |
| 持续执行 | 后台任务持久化、请求幂等、刷新恢复、取消、超时预算、进程中断识别及继续执行；取消不会删除资料。恢复后重新呈现未完成字段确认，已确认数据不重复采纳。 |
| 模型容错 | 传输超时等有限重试；失败候选返回具体原因；中文市盈率等别名规范化；重复无效调用受预算与无进展保护约束，不靠编造数据越过阻断。 |
| 估值状态机 | 正式“确认估值方案并计算”卡只能由确定性准备检查生成；LLM 不能用普通澄清卡宣称基期齐备、承诺缺项 DCF 或把目标公司股价误作 PE 必需输入。连续3轮取证失败的候选在估值任务中会被隔离并继续查找替代证据，保留审计记录且不按零处理。 |
| 年报表格恢复 | 支持 PDF 相邻年度金额无空格粘连、跨行科目名及数值插入科目两半之间的布局；贵州茅台测试会话中的所得税、归母净利润、固定资产折旧和资本开支原文块已通过新版只读复核。 |
| 自动取证续跑 | 长文件读取配额是内部防扫描机制，不再包装成“下一轮继续”的用户选择；每形成一批新无警告候选即刷新定向读取额度。持续估值允许可靠字段分批写入，不因同批另一字段失败而整批丢弃；工具没有实际写入时，LLM 不能声称已完成来源校验或已暂存，候选数量也必须与控制器状态一致。 |
| 性能 | Excel 公式与缓存值逐行并行读取，消除只读表随机访问的平方级开销。默认页面只取最近消息和轻量增量事件，大工具内容按需加载。 |
| 方法适配 | P/E、P/S、EV/EBITDA 按实际所需字段检查，不再强制具备四年 DCF 数据，未用字段不补零。DCF 缺失必要财务仍阻断。 |
| 数据缺失降级 | 多方法任务按方法检查可执行性；至少一种方法完整时，最终集中确认卡明确展示实际方法及数据不足的排除方法，确认后继续计算。原请求、实际方法和排除原因进入任务参数、审计事件、网页及Excel/PDF报告。单一方法核心输入缺失仍阻断，不用猜测值越过。 |
| 检索防空转 | 同一回合完全相同查询会被拒绝；估值任务同一检索目的最多尝试三组不同查询。达到上限后若已有方法可执行则进入方案确认，否则只询问一次补数据或调整方法，不再反复轮询。 |
| 金融计算 | 增加独立算术样例与离线重算检查，修正参考模型年末折现政策；相对估值增加基期指标/同业倍数各±10%的单因素压力测试，明确不是概率区间。 |
| 导出一致性 | CLI、API、Web 使用统一 JSON 复算包，锁定有效输入、金融源码和参数哈希，包含事件、原文块和来源清单。研究 HTML/JSON 正确反映是否已提交估值。 |
| Excel 底稿 | 修正经营必需现金扣除、剩余现金流比例、终值贴现期及参考模型税率；公式不再偏离相应引擎口径。外部公司名/来源文本作为文本处理，不当成 Excel 公式。 |
| PDF 与来源 | 相对估值不再生成空的 DCF 预测页或空 WACC 热力表；实际字段、同业证据、URL/文件哈希及风险进入报告。缺少 Windows 字体时有中文 PDF 字体回退。 |
| 易用性 | 手机对话/资料切换、输入区保持可见、草稿刷新保留、历史搜索、候选年度表与原文核对、中文字段名、结果对话默认折叠、连接设置简化。Tavily 显示配置与实际验证的区别。 |

文件格式：文本型 PDF、DOCX、XLSX、CSV、TSV、HTML、JSON、TXT、MD。旧 XLS 提示转换，扫描 PDF OCR 未接入。长 PDF 有读取预算，支持按指定页段追加读取；解析成功不代表任意复杂表格都已准确识别。

## 交付内容与复现

归档 `output/release/ValuationAgent-20260925-valuation-ready-v7.zip` 包含当前源码、编排、Tool、Prompt、解析与日志模块、前端源码及同版构建、依赖锁、测试、说明和第三方披露。项目没有必需的外部 MCP 依赖；不虚构未使用的 Skill/MCP。`RELEASE_MANIFEST.json` 提供每个文件的哈希和大小；归档不包括密钥、个人研究数据库、node_modules或Git历史。

附带 `acceptance/` 中的合成示例报告、原始合成资料、性能数据与公开来源探测元数据；不打包比亚迪年报全文或任何商业模型权重。PDF 视觉检查采用 PDF 技能的逐页渲染流程；它直接促成删除空章节、改进分页和补充同业来源。

现有环境：

```powershell
conda activate economic_agent
valuationagent serve --host 127.0.0.1 --port 8000
```

## 正式参赛前不能省略的确认

1. 金融小组提供若干真实企业金标准，覆盖不同行业、亏损、重资产、季节性和多业务公司，逐项对账预测、三表关系、终值及敏感性。本轮独立算术和软件测试不替代这一签字。
2. 行业参数工作簿的所有者、授权/许可证、观测区间、样本数和更新口径仍不完整。已如实披露，不能通过修改代码补造数据授权；食品饮料兜底行继续明确降级提示。
3. 现场封闭/半封闭要求需部署专用目录、批准文件清单及实际网络出口白名单。本版为本机单用户工具，并非已做公网鉴权的多租户服务，也不含操作系统级全盘审计。
4. OCR、复杂跨页/合并单元格、完整逐科目三表联动、多业务分部、同业经营可比性仍有专业边界；遇到来源/年度/口径不足时应保留缺口或请求确认，不能承诺“永不阻塞”。

以上属于真实数据和专业验收边界，不应在答辩中描述为已经全自动覆盖。

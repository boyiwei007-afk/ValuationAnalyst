# ValuationAgent 0.2 修复记录

本次根据 2026-09-12 验收结果修复后端和命令行，保留原有参考金融模型可替换的定位。

已完成：

- 默认模式改为 snapshot；显式 demo 不覆盖已提交的合成快照，也不混入标为真实的财务。
- 历史文件和假设文件分角色处理；JSON 导入保存字段引用；未接入的 PDF/Excel/代码取数明确阻断。
- Decimal 使用字符串持久化；独立结果包含企业、日期、币种、模式、版本、输入哈希和实际数据。
- 受约束工具调用循环：读取财务、核对同业、提交执行或要求复核；代码仍保证必需检查。
- 创建不可变新版本；对话修改 WACC 与收入增长；保存更正原因，支持查看历史版本。
- SQLite 成功工具检查点和执行租约；暂停/失败后恢复；已完成 run 重执行幂等。
- 参考模型按依赖复用不受影响的步骤；第三方插件默认使用完整请求缓存键。
- 单独校验情景；合法基准不被非法乐观情景拖垮；没有有效估值时进入复核。
- 摘要数字与核准状态从结构化结果生成；供应商报错脱敏；删除模型会话撤销关联客户端。
- 独立演示数据提供器，插件无需实现 demo 方法；预留提取、收入、资本成本、同业和报告协议。
- 明确参考模型的年度/估值日期/首年现金流与折现期间；补充公告日和可选勾稽规则。
- CLI 分步向导、青绿/深蓝配色、实时双栏/窄屏布局、持续对话、工具详情和结果摘要。
- 新增 CLI chat、history、inspect、review、resume、export；新增 API reviews、revisions、resume、artifacts。
- README、假设/更正示例和金融插件契约已更新。0.1 验收记录保留，作为历史缺陷记录。

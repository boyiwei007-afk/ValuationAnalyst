# v8 生产化加固与验收

日期：2026-09-26。环境：现有 `economic_agent`，未新增隔离环境；本轮未修改 Tushare。

## 结论：可交付候选，不冒称已完成无人值守生产验收

本轮完成了“有附件先读取、无附件公开检索、能计算则审核计算、不能计算则交付有依据的说明文档”的流程加固。

自动化测试与合成附件的真实模型闭环已通过。真实公司零上传能够找到官方年报并提取候选，但本轮贵州茅台公开取证仍没有通过全部数值估值输入检查。因此，不能把这版说成“任意公司、任意文件都可无人值守准确估值”的生产成品。当前适用边界是本机单用户、批准的数据与网络环境、需要专业复核的研究工作台。

## 用户怎么用

1. 在项目目录激活 `economic_agent`，正常退出旧服务后运行 `valuationagent serve --host 127.0.0.1 --port 8000`。浏览器访问 `http://127.0.0.1:8000/`。修改后的 Python 服务需要重启；浏览器需要刷新以载入新构建。
2. 在“模型连接”中连接获准的模型服务。没有模型也能保存资料和下载说明，但不会假装进行了自动研究。
3. 输入公司名称，点击“开始估值”；确认必要的公司、估值日、方法范围。文件可选。
4. 默认“附件优先 + 公开检索补缺”：已有附件先解析，缺项可联网补充，无须逐轮批准补搜。如不希望联网，选择“仅用上传资料（不联网）”。该选项禁止网页搜索，但不等于把外部 LLM 变为本地模型；保密文件仍须使用获准的模型端点。
5. 关键历史数据与假设具备条件后，集中确认正式方案，随后自动进入计算、敏感性与报告。缺失某一方法的资料不应阻塞其他已选且可执行的方法，排除原因会出现在方案中。
6. 看“结果”面板。数值不足时直接下载 PDF/HTML/JSON 说明报告；补数据或重试是可选操作，不需要先按“继续多搜”才能拿到文档。计算阶段失败也有 PDF/JSON 诊断出口，未完成的 Excel 数值底稿不能伪造导出。

## 本轮落地的行为

| 场景 | 实际处理 |
| --- | --- |
| 上传常见资料 | 文本PDF、DOCX、XLSX、CSV、TSV、HTML、JSON、TXT、MD；保留页、工作表、行、段落位置及文件哈希 |
| 损坏/加密/无文字层文件 | 单独标记“不可读取”及原因；保留其他文件与进度；获准联网时允许寻找公开替代来源，不谎称读取成功 |
| 搜索不到完整数据 | 同一数据状态同类最多3次、跨类合计最多6次；查询跨轮去重；预算用尽输出说明，不自动无限重试 |
| 模型决定结束取证 | `finish_response(deliver_outcome=true)` 可直接收敛到说明报告；没有任何实际取证时不能宣称查无数据 |
| 无效继续确认 | 已获授权的补搜不应再次要求授权；重复的无效结束/确认建议由控制器收敛为说明报告 |
| 模型一次多报字段 | 建议每批10—20项、上限80；不截断，仍逐项校验；参数长度限制仍保留 |
| 批量更正混有错误 | 没有匹配新证据的更正不应用，旧值保持；其他有效候选继续保存，确认前不覆盖历史值 |
| 查可比公司的年报 | 支持明确指定检索主体或查询中的唯一证券代码，不再默认用估值对象代码查所有年报 |
| 年报关键行难找 | 原文查询按关键词覆盖和财务数值行排序，同时返回可引用的相邻表头；不把目录匹配当成完成提取 |
| 不同收入科目误判为冲突 | 营业收入、营业总收入、主营业务收入独立保存；不混成同一个revenue，不让用户裁定系统自己制造的冲突 |
| 以缺数确认卡绕过模型 | 拦截“跳过股数再计算”、模型建议用户采信具体未核验股数、普通澄清卡提交正式方案等不可执行路径 |
| 计算输出异常 | 独立复核FCFF、折现值、净债务桥、每股价格、区间和相对估值分位数；不通过则不生成数值结果 |
| 同业口径异常 | 阻止重复代码、已知定价日不一致、FY财务与TTM/forward倍数混用；来源缺失仍披露，不制造元数据 |
| 页面与下载 | 默认结果面板、清楚区分“已计算”和“已出说明”、固定下载入口、手机结果页；下载失败可见，请求体读取受超时控制 |
| 页面性能 | 空闲同步从6秒改为30秒；后台页面执行中降低同步频率；已有轻量快照与流式Excel机制保留 |

报告把已确认事实、待确认候选、带警告候选、假设、计算结果和数据缺口分开。零资料报告不提供虚构价格或数值敏感性。说明报告是一个有记录的交付结果，不等于完成了数值估值。

报告按会话版本保存内容哈希；同版本不重复生成不同内容。正式任务变化会生成对应新版。原始资料与全部工具记录继续留在本地审计存储和JSON包；不声称这是操作系统级全盘审计。

## 验收证据

### 自动测试

- Python最终全量：339项通过，约234秒。另有一次第三方AnyIO弃用告警，不是业务失败。
- 前端：8项业务测试、11项组件检查通过；检查器与生产构建通过。组件检查使用模拟接口，不能替代真实模型验收。
- 9种格式使用相同合成财务内容进行真实解析，再经过原文绑定：100万元正确规范化为1,000,000元，2025年度绑定正确，提取候选不自动确认。
- 覆盖损坏PDF、加密PDF、无文字层PDF、损坏DOCX/XLSX/JSON与可读附件混传；不可读资料不拖住同批其他文件，仍有可导出的报告。
- 覆盖搜索上限跨服务重启保留、明确仅上传时零搜索、部分更正未匹配不破坏已确认值，以及故意破坏每股计算结果后拦截。

### 真实模型、合成附件闭环

脚本：`python scripts/live_upload_check.py --live`。模型端点 `https://api.deepseek.com`，调用名 `deepseek-flash`。调用名是服务商别名，不保证其后台权重永久不变。

在预先确定范围的纯合成任务中，真实模型读取上传资料、提取目标利润与股数和5家同业倍数，形成一张集中方案确认卡。脚本只对自身生成的合成资料自动确认。随后计算并导出PDF、Excel和JSON：

- 净利润200，股数100，同业FY倍数10/12/14/16/18。
- P25 / P50 / P75 每股结果为24 / 28 / 32，与独立算术一致。
- 从模型提取到完成计算约10.22秒；未执行网页搜索。
- 离线复算通过，复算不使用网络。

这证明指定合成样本的LLM→工具→计算→结构化交付链路，不是对真实证券价格的认可，也不是全部公司成功率统计。

### 真实公司、零上传公开取证

`scripts/live_no_upload_check.py --live` 使用同一模型及公开披露检索，不自动确认真实财务事实。最后一轮在线调用（提示版本`.16`）耗时约119.47秒，1次检索，取得一条来源线索和对应官方年报；形成39项候选，其中37项通过来源校验但尚未获最终确认，2项仍需补证。未生成数值估值，已生成PDF/HTML/JSON说明报告。

多轮真实运行暴露并修正了批量字段上限、更正批次整批失败、可比公司代码沿用和检索片段排序问题。过程中还出现“股数是唯一阻塞”“省略股数继续估值”等不成立承诺，已纳入控制器拦截及回归测试；直接交付缺口报告的结束工具也已验证。

最后一轮在线运行仍因“营业总收入”与“营业收入”被错误映射成同一字段，产生了不必要的口径确认卡。最终补丁`.17`拆开科目，并用该次原始会话只读重跑组装检查：假冲突消失，真实缺口仍包括普通股股数及有息负债。此修复通过合成回归与原会话重检查，但没有再把它宣称为一次成功的真实公司在线数值估值。真实零上传链路的稳定性仍属于生产放行前的重要验证项。

本地最后一轮原始证据位于 `var/live-no-upload-20260926-release/`；公开归档只收录验收摘要，不分发官方年报全文。搜索、模型返回随时间变化，源站不可用也不保证必定成功；已有证据的确定性复算与重做在线研究是不同承诺。

### 界面、PDF与性能

- 在1280×720桌面及390×844手机宽度检查结果页。手机页面无横向溢出，资料策略切换、结果标签和固定PDF入口可访问。
- PDF按PDF技能逐页渲染检查中文、边距和分页；检查促成中文字体改进及去除诊断页无意义的空字段。使用本机可用字体，源码不打包Windows字体文件。
- 报告API返回200并通过PDF文本解析；点击内置浏览器下载按钮也发出了200请求，但自动化工具未捕获该浏览器的下载事件，因此不将“已验证本机下载目录落盘”列为通过项。普通Chrome/Edge的最终保存行为仍应在部署机验收。
- 本机合成性能：800行含公式Excel读取中位数0.0383秒；1000条日志轻量快照约28.8KB、中位数45.07ms；8并发快照均200，约108—191ms。使用FastAPI TestClient，不是公网性能或生产SLA。

## 正式生产放行前仍不能省略

1. **真实企业金标准**：覆盖多行业、亏损、复杂集团、空白科目与不同报表格式，多次运行，逐项核对取数、勾稽、预测、终值、敏感性和可比经营口径。现有单公司探测与合成验收不能替代金融人员签字。
2. **OCR与复杂文件**：扫描件、照片、旧XLS尚非原生提取覆盖；目前识别限制并说明/补源，不冒充OCR。高风险不可信文档还需部署隔离进程、资源配额及恶意文件扫描；本轮文件大小和Office解压限额不是完整沙箱。
3. **部署与数据授权**：当前不是公网多租户系统。公网生产需身份认证、租户隔离、访问控制、备份恢复、密钥管理、监控及实际网络白名单；行业参数、公告和供应商数据授权需明确。
4. **停止条件**：可靠输入不足时，正确结果是带证据的说明报告，而非任意价格。不可用放宽单位/期间/口径校验的方式换取表面成功率。

以上边界属于交付状态的一部分，不能在展示中省略。
